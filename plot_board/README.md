# plot_board

列 × 行のグリッドに色とメモを置く、シート風のボードです。

## できること

- **列・行** … 名前変更、追加、途中挿入
- **セル** … 色で塗る、ドラッグで範囲、右クリックで詳細
- **余白メモ** … 表の外に自由配置、右クリックで詳細
- **タグ** … セル・行に付けてフィルタ
- **複数シート** … ブラウザ内に自動保存、JSON のエクスポート / インポート

## 操作（これだけ）

1. **色を選ぶ**（右端は消しゴム）
2. **クリック** → 1セル　**ドラッグ** → 横に範囲（空セルも塗り済みも同じ）
3. **右クリック** → セル・余白メモの詳細
4. **↩ / ⌘Z** → 元に戻す

範囲を直したいときは、消しゴムで削ってから塗り直す。

余白メモは `＋メモ` または表の外を右クリック（新規）。

重なった塗りは、かぶった部分だけ入れ替わり、はみ出した部分は残ります。
