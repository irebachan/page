    シナリオ記法ヘルプ

    基本書式

    #キャラ名
セリフ内容（複数行可能）

    選択肢

    - 選択肢テキスト => ジャンプ先ラベル
- 選択肢テキスト => call ジャンプ先ラベル

    ラベル定義

    @ラベル名

    ラベルへのジャンプ

    @goto ラベル名

    呼び出しと戻り

    @call ラベル名
@return

    シナリオ終了

    @end

    コメント

    // この行はプレビューに表示されず、エクスポート後もコメントとして残ります

    表示ルール（作品ごと）

    ファイル内の @meta 〜 @endmeta に表示ルールを書けます（位置は先頭固定ではありません）。

    @meta
preview.unit=block
preview.maxCharsPerLine=28
preview.maxLines=3
preview.overflow=wrap
@endmeta
    • preview.unit: block / line
    • preview.maxCharsPerLine: 1行あたり文字数
    • preview.maxLines: 表示行数
    • preview.overflow: wrap（折り返し）/ truncate（切り詰め）

    特殊テキスト出力

    「特殊形式で出力」ボタンを使用すると、ゲームエンジン用の特殊記号付きテキストを出力できます：

    • 「。」の後に自動でクリック待ち記号を追加
    • テキストブロック内の行末に改行記号を追加
    • テキストブロックの最後に改ページ記号を追加

    記号は自由にカスタマイズ可能です。

    サンプル

    #ユウ
こんにちは。どこに行きたい？

@choice
- 公園へ => park
- 寄り道 => call detour

@detour
#ミナ
ちょっと寄り道。
@return

@park
#ユウ
公園に着きました。

@goto ending

@ending
#システム
シナリオ終了

@end

    このツールについて

    ノベル試作プレイヤーは、シナリオを編集しながら左側でプレビュー再生できるツールです。共有はテキストのやりとりで行うことを想定しています。

    できること

    • シナリオの編集とプレビュー: 右のテキストエリアでシナリオを書くと、左のビューアで即時プレビューできます。
    • 保存・読み込み・コピー: シナリオをテキストファイルとして保存したり、読み込んだり、クリップボードにコピーしたりできます。
    • 特殊形式での出力: 「出力設定」からティラノスクリプトや Ren'Py 用の記号付きテキストに変換して出力できます。記号はカスタマイズ可能です。

    使い方のイメージ

    1. シナリオを書く（または読み込む）
    2. 左側でプレビューしながら編集する
    3. 完成したら「保存」でテキストファイルにするか、「特殊形式で出力」でゲームエンジン用に変換する
    4. 共有するときは、テキストファイルやコピーしたテキストを渡す

    記法の詳細は「ヘルプ」を参照してください。
