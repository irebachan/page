# ノベル試作プレイヤー

シナリオを編集しながら左側でプレビュー再生できるツールです。共有はテキストのやりとりで行うことを想定しています。

## できること

- **シナリオの編集とプレビュー**: 右のテキストエリアでシナリオを書くと、左のビューアで即時プレビューできます。
- **保存・読み込み・コピー**: シナリオをテキストファイルとして保存したり、読み込んだり、クリップボードにコピーしたりできます。
- **特殊形式での出力**: 「出力設定」からティラノスクリプトや Ren'Py 用の記号付きテキストに変換して出力できます。記号はカスタマイズ可能です。

## 使い方のイメージ

1. シナリオを書く（または読み込む）
2. 左側でプレビューしながら編集する
3. 完成したら「保存」でテキストファイルにするか、「特殊形式で出力」でゲームエンジン用に変換する
4. 共有するときは、テキストファイルやコピーしたテキストを渡す

## 記法

- `#キャラ名` の次の行からがセリフ
- `@ラベル名` でラベル定義
- `@choice` の次に `- 選択肢 => ジャンプ先ラベル` で選択肢
- `@goto ラベル名` でジャンプ
- `@end` でシナリオ終了
- 詳細はツール内の「ヘルプ」を参照してください。
